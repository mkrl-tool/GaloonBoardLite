# 行動予定表（ガルーン連携ホワイトボード風デスクトップアプリ）

Cybozu ガルーン（Garoon）からAPI連携でスケジュールを取得し、オフィスのホワイトボードそっくりのシンプルな画面でメンバーの行先・帰社時間をリアルタイム表示するWindows向け超軽量アプリケーションです。

---

## 🌟 最新アップデート内容

1. **予定がない人は確実に「在席」表示**
   - 現在時刻において進行中の時間指定予定がなく、休暇（年休）でもないメンバーは、行先に確実に **「在席」**（帰社時間は「―」）と表示されます。
   - オフィスの現場で「今その人が席にいるかどうか」が一目で把握できます。

2. **氏名クリックで「1日の全スケジュール」を表示**
   - 行動予定表の **氏名（または行）をクリック** すると、そのユーザーの当日の予定一覧ダイアログがポップアップ表示されます。
   - 午前・午後・夕方の全予定が時系列順にカード形式で並び、**時間帯・メニュー・件名・場所/メモ** が確認できます。
   - 現在進行中の予定には **【現在進行中】** のハイライトが付きます。
   - 当日の予定が0件の場合は「本日の予定はありません（終日在席）」と表示されます。
   - マウスポインターを行の上に置くと指さしアイコン（👆）に変化し、クリックできることが直感的に分かります。

3. **大規模ユーザー（1,000人超）対応の「検索」→「追加」式管理**
   - 設定画面（⚙）の「表示ユーザー設定」タブで、氏名や社員コードでピンポイント検索。
   - 「➕ 追加」したメンバーだけが下部に表示され、チェックを入れた人だけがホワイトボードに表示されます。

4. **「年休（赤）」と「在宅（黄）」の専用カラーバッジ**
   - 年休は赤背景バッジ、在宅は黄色背景バッジでパッと見で識別可能。

5. **文字サイズの拡大・縮小（「-」「+」ボタン）**
   - 歯車の左側にあるボタンで文字サイズと行間を自由自在にスケール調整可能。

6. **超小型・単独動作（わずか 57 KB）**
   - 外部ランタイムやPython、DLL一切不要。
   - **0.05秒で即起動**、メモリ消費はわずか **約15MB**。
   - 標準更新間隔は **20分**。

---

## 🚀 使い方

### 1. 起動
`dist/GaloonBoardLite.exe` をダブルクリックして起動します。

### 2. 操作
- **1日の全スケジュール確認**: メンバーの **氏名をクリック** すると、その日の全予定一覧ダイアログが開きます。
- **文字サイズ変更**: 右上の「-」「+」で文字サイズを好みに調整。
- **ウィンドウ移動**: ボード上をどこでも左ドラッグして移動。
- **リサイズ**: ボードの端や四隅をドラッグして拡大・縮小。
- **最前面固定（📌）**: 右上の「📌」で常に最前面に固定。
- **今すぐ更新（🔄）**: 右上の「🔄」で最新のガルーン予定を取得。
- **設定（⚙）**: ガルーン接続先の設定や表示メンバーの検索・追加。
- **終了（✕）**: 確認ダイアログで「はい」を選ぶと完全に終了します。
